Honest Assessment
Limitations & what we'd improve.
No native mobile app
Web app is fully responsive but a native iOS / Android app would improve on-the-go logging.
Build with React Native and push notifications
No offline mode
Students without data cannot log expenses in the moment.
Add service worker and IndexedDB sync — PWA
Single-user only
No shared budgets for housemates or groups splitting expenses.
Introduce shared group budgets and expense splitting
AI needs third-party APIs
Groq and Gemini are external — degrades to rule-based when both are down.
Embed a lightweight on-device AI model
